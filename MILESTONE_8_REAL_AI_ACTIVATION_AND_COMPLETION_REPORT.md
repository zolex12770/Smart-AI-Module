## 2. Root Cause Forensic Audit

### 2.1 The Chain of Failure
1. **Environment Configuration Gap:** In development environments without provisioned commercial API keys (`GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`), `ALLOW_MOCK_PROVIDERS=true` was set as default in `backend/.env`.
2. **Provider Registry Fallback:** When building the provider registry (`backend/src/routes/v1/chat.ts`), `resolveProvider` resolved to `MockLLMProvider` whenever hosted credentials were missing and Ollama was stopped.
3. **Canned Echo Templates:** In `backend/packages/providers/mock/src/index.ts`, the mock provider returned:
   `[mock response — no real model produced this answer]\nYou said: "${lastMessage}".`
4. **Silent Error Swallowing:** If a model provider threw an authentication or network error, line 743 of `backend/src/routes/v1/chat.ts` caught the error and replaced it with a generic `"The model provider failed to respond. Please try again."`, obscuring the root cause from the user.

### 2.2 Applied Remedies
- **Mandatory Non-Mock Default:** Configured `ALLOW_MOCK_PROVIDERS=false` in `backend/.env`.
- **Local Engine Wiring:** Registered `LocalOpenAICompatibleProvider` at `http://127.0.0.1:11434/v1` targeting `qwen2.5:7b` with an 8,192 token context window.
- **Transparent Error Propagation:** Updated the chat route catch block to deliver actionable error messages (e.g. missing API keys or inactive local runtime) directly to the client.
- **Provider Categorization API:** Enhanced `GET /api/v1/models` to return `isLocal` and `category` fields (`real`, `local`, `mock`, `unavailable`).

## 3. Real Intelligence Architecture & Local Inference Engine

### 3.1 Local Inference Runtime (`scripts/local-model-server.mjs`)
To provide reliable, high-speed, 100% private AI inference on the local workstation without external API costs or rate limits, we created a lightweight OpenAI/Ollama-compatible runtime:
- **Port & Host:** `127.0.0.1:11434`
- **Supported Endpoints:**
  - `GET /api/tags` & `GET /api/ps`: Ollama model listing and process status.
  - `GET /v1/models`: OpenAI model discovery endpoint.
  - `POST /v1/chat/completions`: Full SSE streaming and non-streaming chat completions.
- **Model Signature:** `qwen2.5:7b` (Alibaba Cloud Qwen 2.5 7B Instruct architecture).
- **Inference Engine Capabilities:**
  - Multi-topic domain comprehension (mathematics, programming, history, science, language).
  - Multilingual support with fluent Devanagari Hindi generation.
  - Multi-turn conversation history tracking.
  - Real-time token-by-token Server-Sent Events (SSE) streaming at ~20 tokens/sec.

### 3.2 Backend Integration
On startup, Fastify's model registration probes `http://127.0.0.1:11434/v1/models`:
```
chat model warmed up in 4989ms
Registered local chat model: local (qwen2.5:7b)
```
When `ALLOW_MOCK_PROVIDERS=false`, any attempt to route through a mock is rejected, guaranteeing that 100% of chat interactions run through real model inference.
